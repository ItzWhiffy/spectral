# Spectral

Client-side Fabric mod for Minecraft 26.2 (Fabric Loader 0.19.5, Fabric API 0.161.0+26.2, Java 25).

This repository only hosts the release files. Download the latest `styleui-<version>.jar` from
[Releases](https://github.com/ItzWhiffy/spectral/releases/latest) and put it into your `mods` folder.

Installed copies update themselves: at start the mod checks the latest release here, downloads
a newer jar in the background and swaps it in when Minecraft closes. This can be turned off under
Settings → Updates.
